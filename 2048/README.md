# 2048 · Scripting 适配版

玩法：经典 2048 数字合并游戏，适配 Scripting 离线运行环境。支持触屏滑动、方向按钮、自动保存、最高分记录和撤销一步。

参考所提供的 scripting 版本适配。

## 来源与适配说明


本版改用 Scripting 的 WebViewController 和 Storage，适配触屏界面与游戏逻辑。
